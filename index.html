เครื่องมือช่วยอัปโหลดไฟล์รูปภาพที่ผู้ใช้งานเลือกขึ้นไปยังบัญชี Google Photos ของผู้ใช้งานเอง

วัตถุประสงค์ของแอปพลิเคชัน

อัปโหลดรูปภาพอัตโนมัติ พัฒนาขึ้นเพื่อให้ผู้ใช้งานสามารถนำส่งไฟล์รูปภาพจากอุปกรณ์หรือโฟลเดอร์ที่ผู้ใช้งานกำหนด ไปยังอัลบั้มบน Google Photos ของบัญชีผู้ใช้งานเองได้อย่างสะดวกและเป็นระเบียบ โดยผู้ใช้งานเป็นผู้ควบคุมการเริ่ม/หยุดการทำงาน และเลือกปลายทางด้วยตนเอง หน้านี้เปิดให้เข้าชมข้อมูลสาธารณะได้โดยไม่ต้องเข้าสู่ระบบ

วิธีการทำงานและการใช้สิทธิ์ Google API

  • แอปจะเข้าถึงเฉพาะสิทธิ์ที่จำเป็นต่อการอัปโหลดรูปภาพตามคำสั่งของผู้ใช้งานไปยังบัญชี Google Photos ที่ผู้ใช้งานเลือก
  • ไม่มีการดึงข้อมูลส่วนตัวโดยไม่ได้รับอนุญาต ไม่มีการขายหรือส่งต่อข้อมูลให้บุคคลที่สาม
  • แอปพลิเคชันนี้ไม่สนับสนุนหรืออนุญาตให้ใช้ Google API สำหรับการสร้างหรือเผยแพร่ภาพที่ไม่ยินยอม (Non-Consensual Imagery / AI NCII) หรือเนื้อหาที่ละเมิดกฎหมายและข้อกำหนดการใช้บริการของ Google API
