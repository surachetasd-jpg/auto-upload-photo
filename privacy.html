แอปพลิเคชัน Auto Upload Photo ให้ความสำคัญกับความเป็นส่วนตัวและความปลอดภัยของข้อมูลผู้ใช้งาน เอกสารฉบับนี้อธิบายถึงวิธีที่เราเข้าถึง ใช้ และปกป้องข้อมูลของคุณเมื่อใช้งานบริการ

1. ข้อมูลที่เราเข้าถึง (Data Accessed)

เมื่อคุณเข้าสู่ระบบด้วยบัญชี Google แอปพลิเคชันจะขอสิทธิ์การเข้าถึง (Google OAuth Scopes) เพื่อใช้ในการสร้าง อัปโหลด และจัดการไฟล์ภายใน Google Drive ตามคำสั่งของผู้ใช้งานเท่านั้น เราจะไม่เข้าถึงข้อมูลส่วนตัวอื่นที่ไม่เกี่ยวข้องกับการทำงานของแอป

2. การใช้ข้อมูล (How We Use Information)

ข้อมูลและสิทธิ์การเข้าถึง Google Drive จะถูกนำไปใช้เพื่อวัตถุประสงค์เดียว คือการส่งและอัปโหลดไฟล์ไปยังพื้นที่จัดเก็บ Google Drive ของคุณโดยอัตโนมัติ แอปพลิเคชันไม่มีการเก็บสำเนาไฟล์ของคุณไว้บนเซิร์ฟเวอร์ภายนอก

3. การเปิดเผยข้อมูลต่อบุคคลที่สาม (Data Sharing)

เราไม่มีนโยบายขาย แลกเปลี่ยน หรือเปิดเผยข้อมูลส่วนบุคคลและข้อมูลใน Google Drive ของคุณให้แก่บุคคลที่สาม รวมถึงไม่นำข้อมูลไปใช้เพื่อการโฆษณา

4. การปฏิบัติตามนโยบายข้อมูลผู้ใช้ของ Google (Google API Services User Data Policy)

การใช้และการโอนข้อมูลที่ได้รับจาก Google APIs ของแอปพลิเคชัน Auto Upload Drive จะปฏิบัติตาม Google API Services User Data Policy รวมถึงข้อกำหนดเรื่องการใช้งานแบบจำกัด (Limited Use requirements) อย่างเคร่งครัด
